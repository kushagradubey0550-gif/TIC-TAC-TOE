# Tic Tac Toe - React Native

A simple and interactive Tic Tac Toe game built with React Native. This project demonstrates the use of React Hooks, state management, conditional rendering, and animations to create a smooth mobile gaming experience.

## Features

- Two-player gameplay (X vs O)
- Automatic winner detection
- Draw detection
- Animated winner/draw popup
- Restart game functionality
- Modern dark-themed UI
- Responsive 3x3 game board

## Tech Stack

- React Native
- TypeScript
- React Hooks (`useState`, `useRef`)
- React Native Animated API

## Learning Outcomes

This project helped me understand:

- Component-based architecture in React Native
- State management using `useState`
- Handling user interactions with `TouchableOpacity`
- Conditional rendering
- Game logic implementation
- Basic animations using the Animated API
- Styling with StyleSheet

## Future Improvements

- Single-player mode with AI
- Score tracking
- Sound effects and haptic feedback
- Improved animations
- Online multiplayer support

## Getting Started

```bash
npm install
npx expo start
```
